Sets & Set Operations

A set is a well-defined collection of distinct objects. Enter two sets and choose an operation to see the result step by step.

Set Operation Solver

Solution

Set Theory Reference

A set is written in roster form like A = {1, 2, 3} or set-builder form like A = {x | x is even}.

Union: A ∪ B = {x | x ∈ A or x ∈ B} Intersection: A ∩ B = {x | x ∈ A and x ∈ B} Difference: A − B = {x | x ∈ A and x ∉ B} Power Set: |P(A)| = 2ⁿ where |A| = n De Morgan's: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
Example

A = {1, 2, 3, 4}, B = {3, 4, 5, 6}

A ∪ B = {1, 2, 3, 4, 5, 6}
A ∩ B = {3, 4}
A − B = {1, 2}

Complex Number Reference

Limits & L'Hôpital's Rule

The limit describes function behaviour as input approaches a value. When you get 0/0 or ∞/∞, apply L'Hôpital's Rule.

Limit Evaluator

Enter a function f(x) and the value x approaches. Use: x^2, sqrt(x), sin(x), cos(x), exp(x), log(x)

Solution

Limit Rules & L'Hôpital

lim x→a f(x) = L means f(x) → L as x → a Indeterminate forms: 0/0 or ∞/∞ L'Hôpital's Rule: lim f(x)/g(x) = lim f'(x)/g'(x) Common limits: lim x→0 sin(x)/x = 1 lim x→∞ 1/x = 0 lim x→∞ (1 + 1/n)ⁿ = e
Example — L'Hôpital

lim x→1 (x−1)/(x²−1) → 0/0, so differentiate numerator and denominator:

= lim x→1 1/(2x) = 1/2

Geometric Series Solver

Solution

Series Reference

Geometric Series: S = a + ar + ar² + ar³ + ... If |r| < 1: S = a / (1 − r) (Converges) If |r| ≥ 1: Diverges Partial sum: Sₙ = n(n+1)/2 for Σk from 1 to n

Polynomials

An algebraic expression using variables and constants with non-negative integer powers.

Types & Names

The degree is the highest power of the variable.

Degree 0: constant (e.g. 3) Degree 1: linear (e.g. 5x + 4) Degree 2: quadratic (e.g. 2x² + 3x − 2) Degree 3: cubic (e.g. 5x³ + 3x² − x + 9) Degree 4: quartic (e.g. 3x⁴ − 2x³ + ...) Terms: monomial (1), binomial (2), trinomial (3)
Multiplication Rules
(a+b)² = a² + 2ab + b²
(a−b)² = a² − 2ab + b²
a² − b² = (a+b)(a−b)

Solve equations of the form ax + b = c step by step.

Linear Equation Solver

Enter a linear equation in one variable. Use 'x' as the variable. Examples: 3x - 7 = 2, 2(x + 3) = 14

Solution

Steps to Solve

1. Simplify both sides (distribute, collect like terms) 2. Move variable terms to one side 3. Divide by the coefficient 4. Check: substitute back
Example

Solve: 3a − 1 = 7

3a = 7 + 1 = 8
a = 8/3

Solution

Derivative Rules

d/dx (c) = 0 (Constant) d/dx (xⁿ) = n·xⁿ⁻¹ (Power Rule) d/dx (eˣ) = eˣ (Exponential) d/dx (ln x) = 1/x (Logarithm) d/dx (sin x) = cos x (Trig) d/dx (cos x) = −sin x d/dx (tan x) = sec²x Product: (fg)' = f'g + fg' Quotient: (f/g)' = (f'g − fg')/g²
